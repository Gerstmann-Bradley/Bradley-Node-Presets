This repository provides Bradley's remote asset library for his CC0-licensed presets used with Blender nodes.

Previously, these presets were downloaded and updated through an addon.

Nevertheless, the remote asset library feature has its limitations. See [Blender Issue #161776](https://projects.blender.org/blender/blender/issues/161776) for details.

At the moment, it is therefore not really a replacement for the old addon workflow.

In fact, if you are already using the addon, I recommend continuing to use it rather than switching to the asset library workflow.
